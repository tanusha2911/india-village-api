🇮🇳 India Village API

Explore Indian geographical data from State to Village.

📌 Project Overview
India Village API is a web application that allows users to explore and search Indian geographical information, from states to villages. It provides location-based data through REST APIs and displays useful information through an interactive dashboard.

✨ Features

• Explore Indian states.
• View districts based on selected states.
• View sub-districts based on selected districts.
• Browse villages.
• Search villages by name.
• Secure login using JWT authentication.
• Dashboard with API usage statistics.
• API analytics and response-time information.
• Admin analytics and user management.
• User plan management.

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/tanusha2911/india-village-api.git
cd india-village-api

2. Backend setup

pip install -r requirements.txt
uvicorn main:app --reload

3. Frontend setup

Open another terminal:

cd frontend
npm install
npm run dev

Configure the required environment variables and database settings according to the project configuration.

🎯 Project Objective

The main objective of this project is to provide an easy way to explore Indian geographical data at different administrative levels and access it through a user-friendly web application and REST APIs.
